- **Issue 1 (Resolved):** `python` was originally pointing to a Microsoft Store execution alias.

  - *Fix:* Installed Node.js LTS via winget and MinGit portable into user programs, added to User PATH.

  - *Fix:* Configured CurrentUser execution policy to RemoteSigned.
- **Issue 4 (Resolved):** UTF-8 BOM generated by default PowerShell `Set-Content` disrupted JSON parsing.
