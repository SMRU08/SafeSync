# RAKSHYA VISION — Datasets

This directory houses datasets for the RAKSHYA VISION safety monitoring system.

## Directory Structure
- `raw/`: Permanent, unmodified copies of downloaded datasets (PPE, fire, smoke). Never modified directly.
- `processed/`: Normalized, YOLO-ready training/validation/testing images and labels.

> **Status:** Phase 1 Foundation. No datasets have been downloaded or prepared yet. Dataset collection and processing will occur in Phase 2.
